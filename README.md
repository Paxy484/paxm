# PAXM

PAXM is a binary file format specification and it works like MIDI file but from scratch! PAXM is still beta and it is not full version yet! i created this for fun, so execpt to be not your perfect file format or anything like that

Extra features are:
Deathcore production mode, Speed Metal production mode

If you want use MIDI (not PAXM) itself
i suggest using [midis2jam2](https://midis2jam2.xyz/), it really cool software
